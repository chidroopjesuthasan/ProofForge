# ProofForge

ProofForge is an AI-powered project proof and hiring verification platform.

Candidates can attach GitHub repositories, deployment links, documents, screenshots, and project ZIP files. ProofForge analyzes the evidence and generates a structured ProofForge Dossier with proof strength, skill mapping, architecture summary, and recruiter-friendly verification insights.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS later
- Axios
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- H2 for development
- PostgreSQL later

### AI
- Gemini API first

## MVP Goal

Candidate creates a project, attaches evidence links, uploads a project ZIP, runs AI analysis, and generates a ProofForge Dossier.

## Development Rule

Build phase by phase. Do not add enterprise features before the MVP is stable.
